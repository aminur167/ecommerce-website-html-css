# E-commerce Website

Responsive multi-page e-commerce storefront template built with semantic HTML5 and modern CSS3.

## Features

- Product listing grid with hover effects
- Responsive navigation bar
- Product category filtering layout
- Footer with contact and social links
- Mobile-friendly responsive design
